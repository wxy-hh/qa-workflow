# 思维快捷键（Prompt Shortcuts）

用高度标准化的方法论短语替代长篇 Workflow 指令：这些短语激活模型已内化的认知路径，按需使用，不构成固定流程。与 `qa-workflow.md` 的关系：流程文档规定"什么时候做什么"，本表提供"一句话怎么撬动"。

## 自由 Prompt

### 对抗性审查
- **什么时候用**：方案评审、设计定稿前，怀疑方案有未暴露的假设漏洞。
- **怎么说**：「对这个方案做对抗性审查，优先寻找能推翻核心假设的反例，不要帮它找理由。」
- **激活什么**：攻击假设而非完善方案——幂等性、故障点、边界条件、替代路径。

### 第一性原理
- **什么时候用**：怀疑"题目本身问错了"，现有讨论只是在既定方案上惯性优化。
- **怎么说**：「不要基于现有方案继续设计，从第一性原理重新分析这个问题到底该怎么解。」
- **激活什么**：回到问题的本质约束重新推导，拆掉"既定方案"的锚定效应。

### 消融实验
- **什么时候用**：一次引入多项优化/机制后，需要判断真实收益来自哪里。
- **怎么说**：「给这几项改动设计消融实验，逐项评估独立贡献。」
- **激活什么**：以 Baseline 为起点的对照思维，识别"搭便车"的复杂度——只贡献微量收益的机制应删除。

## 既有技能入口

### 奥卡姆剃刀 / 高内聚低耦合（结构清理）
- **什么时候用**：感觉某模块臃肿、抽象层过多、职责边界混乱。
- **怎么用**：直接调用 `/improve-codebase-architecture`（人工触发专项）。它内建 deletion test 与模块深度词汇表（`codebase-design`），且感知 ADR，不会把有意设计的接缝误判为过度设计。
- **注意**：日常小范围精简在对话里直接口头要求即可，不必启动专项；专项需求经 `qa-workflow.md` 阶段 6 的「转专项」通道承接。

### 批量冲刺（实现全量待办工单）
- **什么时候用**：特性规格拆解的多张工单拓扑依赖清晰、上下文高度连贯，期望 Agent 一次性连续完成全部编码实现。
- **怎么说**：「/implement --all」、「/implement」（缺省工单参数）或「批量实现工单 01-NN」。
- **激活什么**：阶段 4 批量连续冲刺模式，各工单内部自动完成 TDD 红绿循环并自动流转状态（`ready-for-agent` → `done`），全量编码通过后统一输出交付矩阵并流转至阶段 5（真实浏览器验收），消除逐张工单确认的轮次摩擦。
